## 这是什么

一个记录本周开发任务的待办清单：

- **列表页** `index.html`：新增、删除、按关键字筛选、只看未完成
- **详情页** `detail.html`：点任意一条进去看详细说明

数据不再写死在文件里，存在后端的 JSON 文件里，刷新不丢。

## 功能

**前端**

- 新增待办（输入框回车或点「新增」）
- 删除待办（二次确认）
- **标记完成 / 取消完成**（调 PUT 接口，完成的标题会加删除线）
- 按关键字实时筛选、只看未完成
- **三种状态**：加载中 / 空数据 / 请求失败（带「重试」按钮）
- 手机 375px 宽度下正常显示，无横向滚动条

**对话页（任务 4）**

- 流式输出：文字逐字出现，不是转圈后一次性刷出来
- 连续多轮对话，上下文接得上；超过长度上限自动丢弃最早的消息
- 「停止生成」按钮，点了立刻中断
- 出错给人话：没配 Key / Key 无效（401）/ 余额不足（402）/ 限流（429）/ 超时
- **API Key 只在服务器上**，前端任何文件里都找不到它

**工具调用（任务 5）**

- 两个工具：`add_item`（新增待办）、`query_items`（按状态 / 关键字查询）
- 完整链路：自然语言 → 模型判断调哪个工具 → 后端真的读写数据 → 结果回填 → 模型用自然话总结
- 页面上能看到调用了哪个工具、传了什么参数、成功还是失败
- 一次对话可以连续调用多个工具（例如「记一下 XX，然后告诉我还有几条没做完」）
- 模型没有删除和标记完成的权限，被问到时它会明确说做不到，不会编

**后端**

- 5 个接口：查列表、按编号查一条、新增、删除、修改
- 数据存 JSON 文件，服务重启后还在
- 参数校验：缺字段、类型不对返回 400 并说明原因，服务不崩
- 全局错误处理：异常都返回 JSON，不把 HTML 报错栈甩给前端
- 已开启跨域（CORS）

## 本地怎么跑

**必须开两个终端。**

### 终端 A：后端

```powershell
cd D:\webone\server
npm install      # 只有第一次
npm start
```

启动后监听 `http://localhost:4000`。

### 终端 B：前端

```powershell
cd D:\webone
npx serve .
```

打开它给的地址（通常 `http://localhost:3000`）。

> 本地调试时，把 `config.js` 里的 `API_BASE` 换成 `"http://localhost:4000/api"` 并注释掉线上那行。

### 为什么不能直接双击 index.html

浏览器规则：`file://` 协议下不允许网页请求其他地址。双击打开会显示「加载失败」，这是浏览器限制，不是代码问题。

### 为什么后端代码有两个地方

- 本仓库的 `server/`：**本地开发用**
- 独立仓库 [`webone-server`](https://github.com/Ink-saber/webone-server)：**线上部署用**

原因：Railway 会把「根目录有 index.html」的仓库识别成静态网站，导致 Node 服务不被启动。把后端拆到独立仓库后，根目录只有 Node 文件，平台能正确识别。详见「部署记录」。

## 已知问题

- 后端无鉴权，任何人可调用（作业项目，可接受）
- 跨域为 `Access-Control-Allow-Origin: *`，真实项目应写具体域名
- Railway 免费实例闲置后会休眠，首次访问需等待数十秒
- 线上数据文件在容器内，实例重启会重置为 7 条初始数据（本地不受影响）
