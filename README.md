# 第四阶段待办清单

26 级 · 李昊泽 · 一个记录本周任务的待办清单，前端是纯 HTML / CSS / JavaScript，后端是 Node.js + Express + SQLite。

## 这是什么

用来记录我这一周第四阶段任务的网页，一共两个页面：

- **列表页** `index.html`：展示待办，可以按关键字实时筛选
- **详情页** `detail.html`：点任意一条进去，看这条任务的说明

> 前端的数据目前还是写在 `app.js` 顶部（任务 3 会改成从后端接口读取）。
> 后端接口已经写好并能用 `curl` 调通（任务 2），接口说明见 `server/API.md`。

## 功能

**前端（任务 1 完成）**

- 待办列表，用「已完成 / 待办」两种标签区分
- 搜索框输入关键字，列表实时筛选；没有结果时显示提示文字
- 点任务标题跳到详情页，详情页可以返回列表
- 手机屏幕（375px 宽）下正常显示，不出现横向滚动条

**后端（任务 2 完成）**

- 4 个接口：查列表、新增、删除、修改
- 数据存在 SQLite 文件里，服务重启后数据还在
- 参数校验：缺字段、类型不对返回 400 并说明原因，服务不会崩
- 全局错误处理：任何异常都返回 JSON，不会把 HTML 报错栈甩给前端

## 本地打开方式

### 前端（看页面）

方法一：直接双击 `index.html`，用浏览器打开。

方法二：在本目录打开命令行，执行

```bash
npx serve .
```

然后访问终端里提示的地址（通常是 http://localhost:3000）。

### 后端（跑接口）

```powershell
cd server
npm install      # 只需要第一次
npm start
```

看到「接口服务已启动 / http://localhost:4000」就成功了。停止按 `Ctrl + C`。

测试接口：

```bash
curl.exe http://localhost:4000/api/items
```

完整的接口文档（参数、返回示例、curl 命令）见 [server/API.md](server/API.md)。
