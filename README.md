# 待办簿

一个多用户的待办清单，配一个能真正动手记账的 AI 助手。

## 线上地址

| 部分 | 地址 |
| --- | --- |
| 网站 | https://ink-saber.github.io/webone/ |
| 后端接口 | https://webone-server-production.up.railway.app |
| 后端仓库 | https://github.com/Ink-saber/webone-server |

## 这是什么

注册一个账号，就能有自己的一份清单，别人看不到你的数据。

- **清单页**：添加、完成、删除、按关键字搜
- **详情页**：看某一条的说明和创建时间
- **对话页**：跟「小记」说话，它可以直接帮你记一条、也可以帮你查还剩什么没做

## 功能

**账号**

- 注册 / 登录 / 退出，密码用 `scrypt` 加盐哈希，不存明文
- 登录凭证是随机 token，存在浏览器里，7 天有效
- **每个账号只看得到自己的待办**：接口层面按 userId 过滤，换账号登进去是空清单

**清单**

- 添加（回车或点按钮）、完成 / 取消完成、删除（二次确认）
- 按关键字实时筛选（标题和说明都搜）、只看未完成
- 三种状态：加载中 / 空 / 请求失败（带重试）
- 手机宽度下正常显示，不出现横向滚动条

**对话（小记）**

- 流式输出，文字逐字出现
- 连续多轮，上下文接得上；超过长度上限自动丢弃最早的消息
- 「停止生成」按钮
- 出错给人话：没配 Key / Key 无效 / 余额不足 / 限流 / 超时 / 未登录

**工具调用**

- 两个工具：`add_item`（新增）、`query_items`（按状态 / 关键字查）
- 完整链路：自然语言 → 模型决定调哪个 → 后端真的读写数据 → 结果回填 → 模型用自然话总结
- 对话里能直接看到调用了哪个工具、传了什么参数、成功还是失败
- 模型只能操作**当前登录用户**的数据
- 模型没有删除和标记完成的权限，被问到时它会明确说做不到，不会编

## 用起来

1. 打开网站 → 点「注册」，用户名 2~20 位、密码至少 6 位
2. 进入清单页，开始记事情
3. 想省事就切到「对话」，说「帮我记一条：明天交周记」

## 本地怎么跑

**必须开两个终端。**

### 终端 A：后端

```powershell
cd server
npm install      # 只有第一次
npm start
```

启动后监听 `http://localhost:4000`。

首次需要配 Key：把 `server/.env.example` 复制成 `server/.env`，填入 `DEEPSEEK_API_KEY=sk-...`。

### 终端 B：前端

```powershell
npx serve .
```

打开它给的地址（通常 `http://localhost:3000`）。

> 本地调试时，把 `config.js` 里的 `API_BASE` 换成 `"http://localhost:4000/api"`。
> 不能直接双击 `index.html`：`file://` 协议下浏览器不允许网页请求其他地址。

## 技术栈

| 层 | 用了什么 | 为什么这么选 |
| --- | --- | --- |
| 前端 | 原生 HTML / CSS / JavaScript | 不引入框架，把链路跑通、每一行都能讲清 |
| 后端 | Node.js + Express 5 | 和前端同一门语言 |
| 鉴权 | scrypt 加盐哈希 + 随机 token | 用 Node 自带的 crypto，不额外装包 |
| 存储 | JSON 文件（`server/store.js`） | 不依赖原生模块，任何 Node 版本和云平台都能跑；写不进去时自动降级为内存 |
| 大模型 | DeepSeek（OpenAI 兼容接口） | 国内可直连，有免费额度 |
| 前端部署 | GitHub Pages | 静态托管，push 即上线 |
| 后端部署 | Railway | 支持 Node 服务，免费额度 |

| 阿里云函数计算 | ❌ | 函数启动即退出（`CAExited`），沙箱限制，详细日志需付费 |

## 已知问题

- 数据存在容器本地文件里，Railway 实例重建会重置；要真正持久化得接外部数据库
- 没有找回密码、没有邮箱验证
- 跨域是 `Access-Control-Allow-Origin: *`，真实项目应收窄到具体域名
- 没有限制登录失败次数
- 还没有编辑待办内容的入口（接口支持 PUT，页面只用了它的「切换完成」）

## 技术要点

- **鉴权**：登录返回随机 token，前端存 localStorage，之后每个请求带 `Authorization: Bearer`。后端用中间件校验，取不到会话就返回 401，前端自动跳回登录页。
- **数据隔离**：所有待办操作都带上当前用户的 id，改别人的数据会返回 404，看起来就像「没有这条」。
- **流式输出**：后端把上游的 SSE 重新打包推给前端，前端用 `getReader()` 边读边渲染；加了 200ms 心跳防止代理攒包。
- **工具调用**：模型返回 `tool_calls` → 后端执行 → 结果以 `role:"tool"` 回填 → 再请求一次让模型写总结，最多循环 3 轮。
